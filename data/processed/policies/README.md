## Corrections

Where the manual contradicts itself, the extraction replaces the text:

- Section 1.2: `| Telefone / WhatsApp | (67) 3341-4444 |` → `| Telefone | (67) 3341-4444 | | WhatsApp | (67) 3321-4500 |`. Section 7 names (67) 3321-4500 as the WhatsApp channel; (67) 3341-4444 stays as the store phone.
- Section 1.2: `contato@empóriodamusica.com.br` → `contato@emporiodamusica.com.br`. The cover page spells the e-mail domain without the accent.
- Section 3: `Parcela mínima de R$ 100,00` → `Parcela mínima conforme o número de parcelas (ver 3.1)`. Section 3.1 sets the minimum installment by number of installments (R$ 50, R$ 80, R$ 100); the table gives only the 7x-12x minimum.
- Section 3.1: `sem valor mínimo de parcela (exceto abaixo de R$ 50,00)` → `parcela mínima de R$ 50,00`. The original ("no minimum, except below R$ 50,00") contradicts itself; read as a R$ 50,00 minimum.
